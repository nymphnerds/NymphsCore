Install NymphsCore Manager

Download the Manager zip, extract it, and run NymphsCoreManager.exe. Do not run the Manager from inside the zip.

Download Manager Open guide

Install Base Runtime

Use the Manager order: get Windows WSL ready, install the NymphsCore Base Runtime, then add modules from their cards.

Open guide

Install Z-Image Turbo

Install Z-Image Turbo from its module card after the Base Runtime is ready. This installs the local image-generation backend.

Fetch Z-Image Models

After Z-Image is installed, use Fetch Models on the Z-Image module card. The fetch downloads the base Z-Image Turbo model and the selected Nunchaku weight.

Install TRELLIS.2

Install TRELLIS.2 from its module card after the Base Runtime is ready. This installs the local image-to-3D backend.

Fetch TRELLIS Models

After TRELLIS.2 is installed, use Fetch Models on the TRELLIS.2 module card. Start with the recommended default unless you know you need a different quant.
