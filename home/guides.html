Install NymphsCore Manager

Download the Manager zip, extract it, run `NymphsCoreManager.exe`, then open Base Runtime and install or repair the managed runtime.

Base Runtime creates the managed `NymphsCore` WSL distro. Modules should be installed only after the base runtime reports a healthy state.

Troubleshooting

Most support cases start with the Manager Logs page and the newest log file under `%LOCALAPPDATA%\NymphsCore\`.

  • Extract the zip before running the Manager.
  • Update WSL and NVIDIA drivers if setup fails.
  • Check disk space before installing model-heavy modules.
  • Use module repair/update controls before deleting data.

Logs

Manager logs are written under this Windows folder:

%LOCALAPPDATA%\NymphsCore\

When reporting a problem, include the newest `installer-run-*.log` and a screenshot of the Manager page where the problem happened.
