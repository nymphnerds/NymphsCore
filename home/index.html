Local creative tools for Windows

NymphsCore installs and manages local creative modules.

Use the Windows Manager to create the local runtime, install modules, fetch models, open tools, and find logs without building WSL, Python, CUDA, and service environments by hand.

Download Manager Open Wiki Feedback

How it works

NymphsCore separates the base runtime from optional modules. Install the Base Runtime once, then install only the tools you want.

1. Install Base Runtime

The Manager prepares a dedicated `NymphsCore` WSL distro and checks the machine state.

2. Choose modules

Module cards install and manage tools such as image generation, LoRA training, 3D generation, and worldbuilding.

3. Use the Blender addon

The addon connects Blender workflows to the local runtime and installed modules.

Official modules

The Manager loads official modules from the Nymphs registry.

Brain

Local assistant tools, Open WebUI, llama-server, and MCP tooling.

Z-Image Turbo

Local image generation backend with module-owned model fetching.

LoRA

Z-Image Turbo LoRA training workspace with beginner and advanced flows.

TRELLIS.2

Local image-to-3D generation backend.

WORBI

Local-first worldbuilding workspace for lore, characters, timelines, and notes.
