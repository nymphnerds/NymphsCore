Feedback

Feedback and issue reports.

Use this page when setup fails, a module behaves unexpectedly, the Blender addon cannot connect, or a guide is unclear.

Before reporting

A few quick checks make the report easier to understand and easier to fix.

Check the Logs page

Open the Manager Logs page and look for the newest error near the bottom.

Try the module page

If the problem is module-specific, try the module repair, update, start, stop, or logs actions first.

Keep the first confusing point

If the workflow became unclear before it failed, report that exact point too.

What to include

Copy this checklist into your report when possible.

Report checklist

  • What you were trying to do.
  • Which module was involved, if any.
  • What you clicked immediately before the problem.
  • The exact error text, if there was one.
  • A screenshot of the Manager or Blender page.
  • Windows version and GPU model.
  • The newest log file from `%LOCALAPPDATA%\NymphsCore\`.

Log folder: %LOCALAPPDATA%\NymphsCore\

Common report types

Install failed

Include the install step, Windows/WSL state, disk space, and newest installer log.

Model download failed

Include the module name, selected model option, and whether a Hugging Face token was used.

Addon cannot connect

Include Blender version, addon version if visible, and whether the Manager module is running.

Guide feedback

Tell us which step was unclear and what you expected the page to say next.

Where to send it

Use the support channel or issue path linked with your release or Superhive listing. If no channel is available yet, keep the checklist and log file together so the report is ready to send.
